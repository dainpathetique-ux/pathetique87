# ON글터 물티슈 스티커 (90×50mm, 탭형)

- `최종/ON글터_물티슈스티커_칼선포함.ai` : 인쇄용 (PDF 호환 AI). 레이어: 디자인 / 안전선(참고, 기본 숨김) / 작업선 / 칼선(재단선)
- `최종/ON글터_물티슈스티커_칼선포함.pdf` : 동일 내용 PDF
- `시안/` : PNG 시안
- `build.py` : SVG/PNG 생성, `make_ai.py` : 레이어 PDF/AI 생성

규격: 재단 90×50 (본체 81 + 탭 9, 모서리 R4, 탭 R13), 작업선 +1.8mm, 안전선 −1.8mm.
텍스트는 모두 아웃라인 처리, 색상 RGB(딥그린 #395B11 / 주황 #E1AB43).

## CMYK 버전 (인쇄 접수용)
- `최종/ON글터_물티슈스티커_칼선포함_CMYK.ai` / `.pdf` : 모든 벡터 색상 DeviceCMYK, 로고 이미지 2개 ICC(Artifex CMYK SWOP) 변환, RGB 요소 0개.
- `최종/ON글터_물티슈스티커_CMYK_인쇄예상.png` : 같은 프로파일로 되돌린 소프트 프루프(인쇄 예상색).
- `make_cmyk.py` : 생성 스크립트. 색상표: 딥그린 C75 M40 Y100 K40 / 주황 C10 M35 Y95 K0 / 연녹회 C7 M2 Y13 K0 / 세이지 C27 M11 Y39 K0 / 칼선 M100 / 작업선 C100.
