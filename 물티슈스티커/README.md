# ON글터 물티슈 스티커 (90×50mm, 탭형)

- `최종/ON글터_물티슈스티커_칼선포함.ai` : 인쇄용 (PDF 호환 AI). 레이어: 디자인 / 안전선(참고, 기본 숨김) / 작업선 / 칼선(재단선)
- `최종/ON글터_물티슈스티커_칼선포함.pdf` : 동일 내용 PDF
- `시안/` : PNG 시안
- `build.py` : SVG/PNG 생성, `make_ai.py` : 레이어 PDF/AI 생성

규격: 재단 90×50 (본체 81 + 탭 9, 모서리 R4, 탭 R13), 작업선 +1.8mm, 안전선 −1.8mm.
텍스트는 모두 아웃라인 처리, 색상 RGB(딥그린 #395B11 / 주황 #E1AB43).
