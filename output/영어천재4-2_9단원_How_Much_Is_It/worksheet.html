2. 문장 익히기

5영어 문장과 알맞은 우리말 뜻을 선으로 이으세요.

  • ⑴ How much is this scarf?
  • ⑵ It's seven hundred won.
  • ⑶ I want this toy car.
  • ⑷ How much is it?
  • ⑸ It's nine hundred won.
  • ⓐ 이것은 얼마인가요?
  • ⓑ 900원입니다.
  • ⓒ 이 목도리는 얼마인가요?
  • ⓓ 저는 이 장난감 자동차를 원해요.
  • ⓔ 700원이에요.

6괄호 안의 말을 보고 빈칸에 알맞은 영어를 쓰세요.

⑴ (700원) How much is it? → It's hundred won.
⑵ (900원) How much is this scarf? → It's hundred won.
⑶ (줄넘기) I want this . 저는 이 줄넘기를 원해요.
⑷ (목도리) How much is this ? 이 목도리는 얼마인가요?

7낱말을 순서대로 배열하여 문장을 쓰세요. 첫 글자는 대문자로, 끝에는 ? 나 . 를 붙이세요.

⑴ much / How / it / is / ?
→
⑵ want / I / toy car / this / .
→
⑶ seven / It's / hundred / won / .
→

3. 문법 다지기 ①

9문법 정리의 빈칸을 채우세요.

⑴ 가까이 있는 물건의 가격을 물을 때: How is this + 물건 이름?
⑵ 앞에서 말한 물건의 가격을 물을 때: How much is ?
⑶ 원할 때: I this + 물건 이름. 가격을 말할 때: + 숫자 + won.

10문장에서 물건 이름을 찾아 ○표 하세요.

⑴ How much is this scarf?
⑵ I want this toy car.
⑶ I want this jump rope.
⑷ How much is this sweater?

11우리말에 맞는 것을 골라 ○표 하세요.

⑴ How much ( is / it ) this scarf? 이 목도리는 얼마인가요?
⑵ How ( much / small ) is it? 이것은 얼마인가요?
⑶ I ( want / help ) this toy car. 저는 이 장난감 자동차를 원해요.
⑷ I want ( this / it ) jump rope. 저는 이 줄넘기를 원해요.
⑸ It's seven ( hundred / thousand ) won. 700원이에요.
⑹ ( It's / Is ) nine hundred won. 900원입니다.

12괄호 안의 말을 넣어 우리말에 맞는 문장을 쓰세요.

⑴ ( scarf ) 이 목도리는 얼마인가요?
→
⑵ ( toy car ) 저는 이 장난감 자동차를 원해요.
→
⑶ ( 900 ) 900원입니다.
→
