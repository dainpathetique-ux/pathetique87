2. 문장 익히기

4영어 문장과 알맞은 우리말 뜻을 선으로 이으세요.

  • ⑴ Where do you want to go first?
  • ⑵ I'm interested in design.
  • ⑶ What do you want to be?
  • ⑷ I'm watching a video about drones.
  • ⑸ I want to be a drone pilot.
  • ⓐ 나는 드론 조종사가 되고 싶어.
  • ⓑ 너는 무엇이 되고 싶니?
  • ⓒ 나는 디자인에 관심이 있어.
  • ⓓ 어디를 먼저 가고 싶니?
  • ⓔ 나는 드론에 관한 영상을 보고 있어.

5괄호 안의 상황에 맞게 빈칸에 알맞은 말을 쓰세요.

⑵ (영화감독) What do you want to be? → I want to be .
⑶ (프로그래머) → I to a programmer.
⑷ (디자인에 관심) → I'm in design.

3. 문법 다지기 ①

8문법 정리의 빈칸을 채우세요.

⑴ '~이 되고 싶다': want + 직업 (미래의 직업·모습)
⑵ '~에 관심이 있다': be + 관심의 대상
⑶ 직업 이름이 모음(a, e, i, o, u) 소리로 시작하면 a 대신 을 써요.

9문장에서 '직업'을 나타내는 말을 찾아 ○표 하세요.

⑴ I want to be a drone pilot.
⑵ I want to be a writer.
⑶ Do you want to be a programmer?
⑷ She wants to be a traveler.

10알맞은 것을 골라 ○표 하세요.

⑴ I want ( to be / be ) a writer.
⑵ I'm interested ( in / on ) design.
⑶ ( What / Where ) do you want to be?
⑷ ( What / Where ) do you want to go first?
⑸ I want to be ( a / an ) actor.
⑹ I want to be ( a / an ) programmer.

11괄호 안의 말을 넣어 우리말에 맞는 문장을 쓰세요.

⑴ ( writer ) 나는 작가가 되고 싶어.
→
⑵ ( traveler ) 나는 여행가가 되고 싶어.
→
⑶ ( drones ) 나는 드론에 관심이 있어.
→
