⑴ 지금 하고 있는 일: 동사 + 동사-ing (현재진행형)
⑵ -e로 끝나는 동사: e를 빼고 -ing (come → )
⑶ 단모음 + 단자음: 마지막 글자를 한 번 더 쓰고 -ing (run → )
⑷ 묻기: What he doing? 대답: He listening to music.

10문장에서 현재진행형(be동사 + 동사-ing)을 찾아 ○표 하세요.

⑴ He's watering the flowers.
⑵ She's listening to music.
⑶ I'm cleaning the wall.
⑷ They're painting the wall.

11알맞은 말을 골라 ○표 하세요.

⑴ What ( is / are ) he doing?
⑵ He ( is / are ) listening.
⑶ come → ( comeing / coming )
⑷ run → ( runing / running )
⑸ swim → ( swiming / swimming )
⑹ He ( look / looks ) happy.

12괄호 안의 말을 써서 우리말에 맞는 현재진행형 문장을 쓰세요.
