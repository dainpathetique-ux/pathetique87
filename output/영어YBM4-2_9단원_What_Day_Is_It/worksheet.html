3. 문법 다지기 ①

9문법 정리의 빈칸을 채우세요.

⑴ 요일을 물을 때: What is it?
⑵ 요일을 말할 때: + 요일 (It's Monday.)
⑶ 요일 이름의 첫 글자는 항상 ( 대문자 / 소문자 )로 써요. → ○표 하세요.
⑷ 활동이 있다고 말할 때: I a / an + 활동 (an art class)

10문장에서 요일 이름을 찾아 ○표 하세요.

⑴ It's Monday.
⑵ It's Wednesday today.
⑶ It's Friday. Have a good day!
⑷ It's Sunday. I have a trip.

11우리말에 맞는 것을 골라 ○표 하세요.

⑴ ( What / It's ) day is it? 무슨 요일이지?
⑵ It's ( Monday / monday ). 월요일이야.
⑶ I have ( a / an ) art class today. 오늘 미술 수업이 있어.
⑷ ( It's / It ) Wednesday. 수요일이야.
⑸ Have a ( good / day ) day! 좋은 하루 보내세요!
⑹ It's time ( for / to ) school. 학교 갈 시간이야.

12괄호 안의 말을 보고 우리말에 맞는 영어 문장을 쓰세요.

⑴ ( 화요일 ) 화요일이야.
→
⑵ ( 토요일 ) 토요일이야.
→
⑶ ( art class ) 오늘 미술 수업이 있어.
→
