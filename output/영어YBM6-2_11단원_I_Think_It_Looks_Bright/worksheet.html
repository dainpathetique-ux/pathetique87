3. 문법 다지기 ①

8문법 정리의 빈칸을 채우세요.

⑴ 느낌을 나타낼 때 look, smell, sound 같은 동사를 써요.
⑵ 감각동사 문장: 주어 + 감각동사 + 예) It + 형용사
⑶ 동의할 때: I think , too. 동의하지 않을 때: I think so.

9문장에서 '형용사'를 찾아 ○표 하세요.

⑴ It looks interesting.
⑵ I think it looks dark.
⑶ The skirt looks soft.
⑷ This board game looks boring.

10알맞은 것을 골라 ○표 하세요.

⑴ It ( looks / look ) bright.
⑵ ( What / How ) do you think?
⑶ I think ( so / too ), too.
⑷ I ( don't / not ) think so.
⑸ It ( looks / is ) dark. 그것은 어두워 보여.
⑹ I'm ( bored / boring ). 나는 지루해.

11괄호 안의 말을 넣어 우리말에 맞는 문장을 쓰세요.

⑴ ( bright ) 그것은 밝아 보여.
→
⑵ ( dangerous ) 나는 그것이 위험해 보인다고 생각해.
→
⑶ ( cheap ) 그것은 싸 보여.
→
