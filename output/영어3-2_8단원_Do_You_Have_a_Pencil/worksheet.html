2. 문장 익히기

5영어 문장과 알맞은 우리말 뜻을 선으로 이으세요.

  • ⑴ Do you have a pencil?
  • ⑵ No, I don't.
  • ⑶ I have crayons.
  • ⑷ Thank you.
  • ⑸ I don't have an eraser.
  • ⓐ 고마워.
  • ⓑ 나는 지우개가 없어.
  • ⓒ 너는 연필을 가지고 있니?
  • ⓓ 나는 크레용을 가지고 있어.
  • ⓔ 아니, 없어.

6괄호 안을 보고 Yes, I do. 또는 No, I don't. 로 대답을 쓰세요.

⑴ (연필 있음) Do you have a pencil? →
⑵ (자 없음) Do you have a ruler? →
⑶ (풀 있음) Do you have a glue stick? →
⑷ (지우개 없음) Do you have an eraser? →

7낱말을 순서대로 배열하여 문장을 쓰세요. 첫 글자는 대문자로, 끝에는 ? 나 . 를 붙이세요.

⑴ you / Do / a ruler / have / ?
→
⑵ have / I / crayons / .
→
⑶ don't / I / an eraser / have / .
→

3. 문법 다지기 ①

9문법 정리의 빈칸을 채우세요.

⑴ 물건이 있는지 물을 때: you have a + 물건 이름?
⑵ 있으면 Yes, I . 없으면 No, I .
⑶ 물건이 한 개일 때 이름 앞에 a 또는 을 붙여요. 모음 소리로 시작하면 을 써요.
⑷ 물건이 두 개 이상이면 a를 쓰지 않고 단어 뒤에 를 붙여요.

10a 와 an 중 알맞은 것에 ○표 하세요.

⑴ ( a / an ) pencil
⑵ ( a / an ) eraser
⑶ ( a / an ) ruler
⑷ ( a / an ) notebook

11우리말에 맞는 것을 골라 ○표 하세요.

⑴ ( Do / Is ) you have a ruler? 너는 자가 있니?
⑵ Yes, I ( do / don't ). 응, 있어.
⑶ No, I ( do / don't ). 아니, 없어.
⑷ I ( have / has ) a melon. 나는 멜론이 있어.
⑸ I have ( crayon / crayons ). 나는 크레용(여러 개)이 있어.
⑹ I ( don't / not ) have a pencil. 나는 연필이 없어.

12괄호 안의 물건으로 '너는 ~을 가지고 있니?' 하고 묻는 문장을 쓰세요.

⑴ ( ruler ) 너는 자가 있니?
→
⑵ ( eraser ) 너는 지우개가 있니?
→
⑶ ( notebook ) 너는 공책이 있니?
→
