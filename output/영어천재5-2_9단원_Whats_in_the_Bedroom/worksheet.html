2. 문장 익히기

5영어 문장과 알맞은 우리말 뜻을 선으로 이으세요.

  • ⑴ What's in the bedroom?
  • ⑵ There is a bookshelf.
  • ⑶ There are two chairs.
  • ⑷ This is my new house.
  • ⑸ They are beautiful.
  • ⓐ 2개의 의자가 있어.
  • ⓑ 그들은 아름다워.
  • ⓒ 침실에 무엇이 있니?
  • ⓓ 이곳은 나의 새로운 집이야.
  • ⓔ 책장이 있어.

6괄호 안의 물건을 보고 There is / There are 로 대답을 완성하세요.

⑴ (a sofa) A: What's in the living room? B: There a sofa.
⑵ (two chairs) A: What's in the garden? B: There two chairs.
⑶ (a bathtub) A: What's in the bathroom? B: is a bathtub.
⑷ (a guitar) A: What's in the bedroom? B: There a guitar.

7낱말을 순서대로 배열하여 문장을 쓰세요. 첫 글자는 대문자로, 끝에는 ? 나 . 를 붙이세요.

⑴ in / What's / the bedroom / ?
→
⑵ is / There / a bookshelf / .
→
⑶ are / There / two chairs / .
→

8대화의 빈칸에 알맞은 말을 보기에서 골라 쓰세요.

보기is  ·  are  ·  Look  ·  Where
⑴ A: This my new house. This is the kitchen.
⑵ B: is the bed? A: Here. at this.
⑶ B: What's in the bedroom? A: There a bookshelf.
⑷ A: There two chairs. B: They are beautiful.

3. 문법 다지기 ①

9문법 정리의 빈칸을 채우세요.

⑴ 장소에 있는 것 묻기: in the bedroom? (What + be동사)
⑵ '~이 있다': 하나일 때 There , 둘 이상일 때 There
⑶ '이것 좀 봐'처럼 시키는 문장은 동사로 시작해요. ( at this.)
⑷ 가까운 한 가지는 (이것), 여럿은 (그것들)

10문장에서 be동사(is, are)를 찾아 ○표 하세요.

⑴ There is a bookshelf.
⑵ There are two chairs.
⑶ This is the kitchen.
⑷ They are beautiful.

11알맞은 말을 골라 ○표 하세요.

⑴ There ( is / are ) a sofa.
⑵ There ( is / are ) two chairs.
⑶ ( This / They ) is my house.
⑷ ( This / They ) are beautiful.
⑸ ( Look / Looks ) at this.
⑹ ( What / Where ) is the bed?

12괄호 안의 말을 이용하여 우리말에 맞는 문장을 쓰세요.

⑴ ( what, in, the bedroom ) 침실에 무엇이 있니?
→
⑵ ( there, a bookshelf ) 책장이 있어.
→
⑶ ( there, two chairs ) 2개의 의자가 있어.
→

13틀린 곳을 찾아 바르게 고쳐 쓰세요.

보기하나 → is  ·  둘 이상 → are  ·  여럿 → They
⑴ There are a sofa.
→
⑵ There is two chairs.
→
⑶ This are beautiful.
→
