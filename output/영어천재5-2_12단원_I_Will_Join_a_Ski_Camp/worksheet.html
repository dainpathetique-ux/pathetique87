  • ⑶ I want to join the ski camp, too.
  • ⑷ That sounds fun.
  • ⑸ Do you like skiing?
  • ⓐ 재밌겠다.
  • ⓑ 나도 스키 캠프에 참여하고 싶어.

6괄호 안의 동사를 써서 앞으로 할 일을 말하는 대답을 완성하세요.

⑵ (take) B: I will a coding class this Sunday.
⑶ (visit) B: I will the museum this winter.

3. 문법 다지기 ①

9문법 정리의 빈칸을 채우세요.

⑴ 앞으로 할 일을 말할 때: 조동사 + 동사원형
⑵ 앞으로 할 일 묻기: What you do this winter?
⑶ '~하고 싶다': want to 뒤에는 동사 이 와요.
⑷ 문장 끝의 는 '~도'라는 뜻이에요.
⑸ 좋아하는 것 묻기: you like skiing?

10문장에서 will 뒤에 오는 동사원형을 찾아 ○표 하세요.

⑴ I will join a ski camp.
⑵ I will take a coding class.
⑶ I will visit the museum.
⑷ I will learn coding.

11알맞은 말을 골라 ○표 하세요.

⑴ I ( will / wills ) join it.
⑵ I will ( take / takes ) it.
⑶ What ( will / are ) you do?
⑷ I want ( join / to join ) it.
⑸ I want to join, ( to / too ).
⑹ ( Do / Are ) you like skiing?

12괄호 안의 말을 이용하여 우리말에 맞는 문장을 쓰세요.

⑴ ( I, will, join, a ski camp ) 나는 스키 캠프에 참여할 거야.
→
⑵ ( I, will, take, a coding class ) 나는 코딩 수업을 들을 거야.
→
⑶ ( what, will, you, do, this winter ) 너는 이번 겨울에 무엇을 할 거니?
→

13틀린 곳을 찾아 바르게 고쳐 쓰세요.

보기will + 동사원형  ·  want to + 동사원형  ·  will 뒤에는 to가 없어요
⑴ I will joined a ski camp.
→
⑵ I want join the ski camp, too.
→
⑶ I will to take a coding class.
→
