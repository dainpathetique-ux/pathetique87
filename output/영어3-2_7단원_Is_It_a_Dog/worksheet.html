2. 문장 익히기

5영어 문장과 알맞은 우리말 뜻을 선으로 이으세요.

  • ⑴ Is it a zebra?
  • ⑵ Yes, it is.
  • ⑶ What's that?
  • ⑷ It's big.
  • ⑸ No, it isn't.
  • ⓐ 저것은 무엇이니?
  • ⓑ 그것은 크다.
  • ⓒ 그것은 얼룩말이니?
  • ⓓ 아니, 그렇지 않아.
  • ⓔ 응, 그래.

6괄호 안의 동물을 보고, Yes, it is. 또는 No, it isn't. 로 대답을 쓰세요.

⑴ (개) Is it a dog? →
⑵ (고양이) Is it a bird? →
⑶ (얼룩말) Is it a zebra? →
⑷ (여우) Is it a bear? → It's a .

7낱말을 순서대로 배열하여 문장을 쓰세요. 첫 글자는 대문자로, 끝에는 ? 나 . 를 붙이세요.

→
⑵ big / It's / .

3. 문법 다지기 ①

9문법 정리의 빈칸을 채우세요.

⑴ 어떤 동물인지 물을 때: it a + 동물 이름?
⑵ 맞으면 Yes, it . 아니면 No, it .
⑶ 크기나 생김새를 말할 때: + big, small, cute.
⑷ big, cute, yellow처럼 크기·생김새·색을 나타내는 말을 ( )라고 해요.

10문장에서 크기·생김새·색을 나타내는 말(형용사)을 찾아 ○표 하세요.

⑴ It's big.
⑵ It's a cute cat.
⑶ Wow, it's very small!
⑷ It's a yellow bird.

11우리말에 맞는 것을 골라 ○표 하세요.

⑴ ( Is / Are ) it a dog? 그것은 개니?
⑵ Yes, it ( is / isn't ). 응, 그래.
⑶ ( It's / Is ) small. 그것은 작다.
⑷ No, it ( is / isn't ). 아니, 그렇지 않아.
⑸ Is ( it / its ) a bear? 그것은 곰이니?
⑹ ( What's / What ) that? 저것은 무엇이니?

12괄호 안의 동물로 '그것은 ~이니?' 하고 묻는 문장을 쓰세요.

⑴ ( zebra ) 그것은 얼룩말이니?
→
⑵ ( bear ) 그것은 곰이니?
→
⑶ ( fox ) 그것은 여우니?
→
