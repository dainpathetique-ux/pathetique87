  • ⑴ How's the weather?

  • ⑶ Come here, please.
  • ⑷ It's snowing.
  • ⑸ Let's go outside.
  • ⓐ 눈이 와.
  • ⓑ 밖으로 나가자.
  • ⓒ 날씨가 어때?
  • ⓓ 여기로 와 줘.
  • ⓔ 화창해.

3. 문법 다지기 ①

8문법 정리의 빈칸을 채우세요.

⑴ 날씨를 물을 때: the weather?
⑵ 날씨를 말할 때: + 날씨를 나타내는 말. (예: It's sunny.)
⑶ '~하자'라고 말할 때: + 동작을 나타내는 말.
⑷ How's 는 How , Let's 는 Let 를 줄인 말이에요.

9문장에서 날씨를 나타내는 말을 찾아 ○표 하세요.

⑴ It's sunny.
⑵ It's cloudy.
⑶ It's snowing.
⑷ It's cold.

10우리말에 맞는 것을 골라 ○표 하세요.

⑴ ( How's / What ) the weather?
⑵ ( It's / It ) sunny. 화창해.
⑶ It's ( snow / snowing ). 눈이 와.
⑷ ( Let's / Let ) go outside.
⑸ Come ( here / home ), please.
⑹ ( Watch / Look ) out! 조심해!

11괄호 안의 날씨로 '~해.' 하고 대답하는 문장을 쓰세요.

⑴ ( cloudy ) 흐려.
→
⑵ ( cold ) 추워.
→
⑶ ( sunny ) 화창해.
