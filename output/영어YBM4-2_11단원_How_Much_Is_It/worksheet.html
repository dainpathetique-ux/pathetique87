2. 문장 익히기

5영어 문장과 알맞은 우리말 뜻을 선으로 이으세요.

  • ⑴ How much is it?
  • ⑵ It's one dollar.
  • ⑶ Can I help you?
  • ⑷ Six key rings, please.
  • ⑸ Here you are.
  • ⓐ 여기 있어요.
  • ⓑ 열쇠고리 6개 주세요.
  • ⓒ 이것은 얼마인가요?
  • ⓓ 도와드릴까요?
  • ⓔ 1달러입니다.

6괄호 안의 가격을 보고 빈칸에 알맞은 말을 쓰세요.

⑴ (900원) How much is it? → It's nine won.
⑵ (1달러) How much is this cup? → It's one .
⑶ (1,000원) How much is this pencil? → It's one won.
⑷ (도와드릴까요?) I help you? → Yes, please.

3. 문법 다지기 ①

9문법 정리의 빈칸을 채우세요.

⑴ 가격을 물을 때: How is it?
⑵ it 대신 물건 이름을 넣어 물을 수 있어요: How much is pencil?
⑶ 물건이 여러 개(복수)일 때: How much are / they?
⑷ 가격을 말할 때: It's + + 화폐단위 (won, dollar)
⑸ '도와드릴까요?': I help you? → Yes, .

10문장에서 가격(숫자 + 화폐단위)을 나타내는 말을 찾아 ○표 하세요.

⑴ It's nine hundred won.
⑵ It's one dollar.
⑶ It's one thousand won.
⑷ These are one hundred won.

11우리말에 맞는 것을 골라 ○표 하세요.

⑴ ( How / What ) much is it? 이것은 얼마인가요?
⑵ How much ( is / are ) it? 이것은 얼마인가요?
⑶ How much ( is / are ) these? 이것들은 얼마인가요?
⑷ It's nine ( hundred / thousand ) won. 900원입니다.
⑸ ( Can / Here ) I help you? 도와드릴까요?
⑹ Six key ( ring / rings ), please. 열쇠고리 6개 주세요.

12괄호 안의 말을 보고 우리말에 맞는 영어 문장을 쓰세요.

⑴ ( this hat ) 이 모자는 얼마인가요?
→
⑵ ( 1,000원 ) 1,000원입니다.
→
⑶ ( these ) 이것들은 얼마인가요?
→
