2. 문장 익히기

4영어 문장과 알맞은 우리말 뜻을 선으로 이으세요.

  • ⑴ How can I get to the police station?
  • ⑵ You can get there by subway.
  • ⑶ Take Bus Number 38.
  • ⑷ It's behind the bank.
  • ⑸ You can't miss it.
  • ⓐ 그것은 은행 뒤에 있어.
  • ⓑ 꼭 찾을 수 있을 거예요.
  • ⓒ 경찰서에 어떻게 갈 수 있어?
  • ⓓ 38번 버스를 타세요.
  • ⓔ 지하철을 타고 갈 수 있어.

5괄호 안의 상황에 맞게 빈칸에 알맞은 말을 쓰세요.

⑴ (지하철) How can I get to the hospital? → You can get there by .
⑵ (버스) How can I get to the bank? → You can get there .
⑶ (은행 뒤) Where is the police station? → It's the bank.
⑷ (38번, 해운대) Take Bus Number and get off at .

6낱말을 순서대로 배열하여 문장을 쓰세요. 첫 글자는 대문자로, 끝에는 ? 나 . 를 붙이세요.

3. 문법 다지기 ①

8문법 정리의 빈칸을 채우세요.

⑴ 교통수단을 말할 때: 전치사 + 교통수단 (a / the 같은 관사 없이)
⑵ 가는 방법을 물을 때: can I to + 장소?
⑶ 대답할 때: You can get by + 교통수단.

9문장에서 '교통수단'을 나타내는 말을 찾아 ○표 하세요.

⑴ You can get there by subway.
⑵ You can get there by bus.
⑶ Take Bus Number 38 and get off.
⑷ You can get there by airplane.

10우리말에 맞는 것을 골라 ○표 하세요.

⑴ You can get there ( by / on ) subway.
⑵ You can get there by ( a bus / bus ).
⑶ ( How / What ) can I get to the gallery?
⑷ How can I get ( to / at ) the station?
⑸ It's ( behind / by ) the bank. 은행 뒤에 있어.
⑹ Get ( off / on ) at Haeundae. 해운대에서 내리세요.

11괄호 안의 말을 넣어 우리말에 맞는 문장을 쓰세요.

⑴ ( the hospital ) 병원에 어떻게 갈 수 있어?
→
⑵ ( subway ) 지하철을 타고 갈 수 있어.
→
⑶ ( the gallery ) 미술관에 어떻게 갈 수 있어?
→
