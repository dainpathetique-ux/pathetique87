2. 문장 익히기

4영어 문장과 알맞은 우리말 뜻을 선으로 이으세요.

  • ⑴ What season do you like?
  • ⑵ I like autumn because I can go camping.
  • ⑶ That's right.
  • ⑷ Autumn is a great season.
  • ⑸ Thanks for helping me.
  • ⓐ 가을은 멋진 계절이야.
  • ⓑ 너는 어떤 계절을 좋아해?
  • ⓒ 도와줘서 고마워.
  • ⓓ 맞아.
  • ⓔ 나는 캠핑을 갈 수 있어서 가을을 좋아해.

5괄호 안의 상황에 맞게 빈칸에 알맞은 말을 쓰세요.

⑴ (봄) What season do you like? → I like .
⑵ (겨울) What season do you like? → I winter.
⑶ (가을, 캠핑) → I like autumn I can go camping.
⑷ (도와줘서) Thanks me.

3. 문법 다지기 ①

8문법 정리의 빈칸을 채우세요.

⑴ 좋아하는 계절을 물을 때: What do you like?
⑵ 계절과 이유를 함께 말할 때: I like + 계절 + + 이유
⑶ 동의할 때: That's . 고마움: Thanks for + 동사-

9문장에서 '계절'을 나타내는 말을 찾아 ○표 하세요.

⑴ I like autumn because I can go camping.
⑵ Autumn is a great season.
⑶ I like spring.
⑷ Winter is a great season.

10알맞은 것을 골라 ○표 하세요.

⑴ ( What / How ) season do you like?
⑵ I like autumn ( because / but ) I can go camping.
⑶ ( That's / This ) right.
⑷ Thanks for ( help / helping ) me.
⑸ Autumn is a great ( season / seasons ).
⑹ What season do you ( like / likes )?

11괄호 안의 말을 넣어 우리말에 맞는 문장을 쓰세요.

⑴ ( spring ) 나는 봄을 좋아해.
→
⑵ ( season ) 너는 무슨 계절을 좋아하니?
→
⑶ ( help ) 도와줘서 고마워.
→

12틀린 곳을 찾아 바르게 고쳐 쓰세요.

보기season  ·  because  ·  -ing

→
