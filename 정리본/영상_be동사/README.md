# be동사 3분 완성 — 설명 영상

- `be동사_3분완성.mp4` — 1920×1080, 약 2분 34초. 슬라이드 애니메이션 + 합성 음성 내레이션.
- `내레이션_대본.txt` — 각 장면 대본. **선생님 목소리로 다시 녹음해 끼우려면 이 대본을 순서대로 읽으세요.**

## 중요: 목소리에 관하여
이 영상의 음성은 선생님 목소리가 아니라 **오프라인 합성 음성**입니다. 음성 복제 서비스는 이 작업 환경에서 접속이 차단되어 선생님 목소리로는 만들 수 없었습니다. 합성 음성은 영어 발음이 약해 영어 단어를 한글 발음(에이엠·이즈·아알)으로 넣었습니다.

## 선생님 목소리로 바꾸는 법
1. `내레이션_대본.txt`를 보고 장면 순서대로 녹음합니다(장면별 권장 길이 표시됨).
2. 녹음 파일을 주시면 영상의 화면·타이밍은 그대로 두고 음성만 교체해 드립니다.

## 다시 만들기 (src/)
```
node shoot.cjs                 # slides.html → frames/*.png (Playwright/Chromium)
python3 -I gen_audio.py        # script.json → seg/*.wav + meta.json (합성 음성)
python3 build_vid.py           # frames + seg → be_verb_3min.mp4 (ffmpeg)
```
화면 문구는 `slides.html`, 대본·타이밍은 `script.json`에서 고칩니다.
