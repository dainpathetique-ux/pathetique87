조건은 늘 "주어진 어구만을 한 번씩 모두 사용", 철자 오류는 단어당 감점. 본문 문장을 그대로 쓰게 하지 않고 요약·재진술·적용·대화로 바꾼 문장의 빈칸을 채우게 했다. 어구는 후치 수식(분사구·관계절·similar to that between ~), 병렬(lost ~ and faced ~), to부정사 목적(in order to, a means to acquire) 단위로 잘려 있었다. 기출 예: (B) that / infants / their / an oxytocin feedback loop / activate / between / mothers and / similar to → activate an oxytocin feedback loop similar to that between mothers and their infants.

학습 우선순위 (기출 형식 유지 전제)

  • ① 재진술문 조립력 — 원문 통암기가 아니라 분사구·관계절·병렬·to부정사 덩어리를 문장 구조로 다시 세우는 연습. 이 정리본의 서술형 예상은 모두 그 연습용(학교 선생님이 같은 문장을 쓴다는 보장은 없다).
  • ② 어법 3문항 연속 — 관계사(who/which/that/what/전치사+관계대명사), 병렬 동사 형태, 준동사, 교과서 언어 형식 4개(had been p.p. / 재귀대명사 강조 / It is ~ that / If it had not been for ~).
  • ③ 주제 4문항 연속 — 지문마다 요지 한 줄과 영어 요약문으로 선지 어휘(복수형 추상명사) 감각 익히기.
  • ④ 워드마스터 — 뜻 암기만으론 부족. 새 문맥 공통 빈칸·문맥 어휘, 파생어(품사 전환), 철자 혼동어.
  • ⑤ 내용 일치(Booster 12강) — 수치·고유명사 표로 정리.
확정하지 못한 것 [미확정 — 원장님 확인 필요]
  • 직전 시험 지문의 출처별(교과서·부교재·모의) 비중은 시험지만으로는 알 수 없음.
  • 모의고사: 분석본 수록 18지문만 수록. 18·19, 25~28, 43~45번의 범위 포함 여부 미확인.
  • 교과서 본문 외 읽기(View & Learn, Wrap Up, Dive into Culture, Write & Share)·듣기 대본의 범위 포함 여부 미확인 → 본문 외 읽기는 한 줄 요약만 수록.
  • Booster는 강마다 분석지의 1~4번 네 지문만(13강 제외). 모의 분석본은 이미지 판독이라 인쇄 전 원본 대조 권장.
이 정리본의 표기 약속

· 지문 전문·전체 해석은 싣지 않는다. 원문 인용은 어법·빈칸 포인트에 필요한 짧은 구절만. · 영어 요약문과 서술형 문장은 원문·분석지를 바탕으로 새로 쓴 재진술문(창작)이다. · (ruining ×) = 어법 문제에서 오답으로 바꿔 낼 형태. · ★ = 교과서 언어 형식 또는 분석지 1순위 표시. · ▶ = 정답(가리고 풀 것). · [추정]/[미확정] = 자료에 그렇게 표시된 내용.
